 # Meu Blog Literário

Bem-vindo ao meu Blog Literário!

Este site foi criado para compartilhar curiosidades, ideias e informações sobre livros e sobre a importância da leitura.

## Sobre o projeto

Neste blog você encontrará:

- Curiosidades sobre livros;
- Textos sobre leitura;
- Dicas para leitores;
- Um vídeo sobre o poder da leitura.

## Vídeo

O site também apresenta o vídeo "O Incrível Poder da Leitura", mostrando a importância de criar o hábito de ler.
